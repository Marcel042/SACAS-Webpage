# SACAS College Website: Presentation Guide

## Simple explanation

> “This is the public website for Sam Ale College of Advanced Studies. Visitors can learn about the college, explore its programmes, prepare an application enquiry, and contact admissions. It is built with HTML, CSS, and JavaScript and runs in a browser. It has no college portal, sign-in, backend, or database.”

## What to demonstrate

1. Double-click `index.html` to open the website.
2. Use the navigation to show Home, About, Programmes, Admissions, and Contact.
3. In About, show the college story and Professor Sam O. Ale profile. Explain that his portrait is a placeholder until the intended photo is available.
4. Choose a College of Education or IJMB/JUPEB application and move through its three steps.
5. Select a result file or picture and explain it remains on the device; it is not uploaded.
6. Show the contact phone and email links.
7. Explain that submitting a form prepares an email for the visitor to review and send.

## The code files

- `index.html` contains the website content and form fields.
- `styles.css` controls the SACAS colours, layout, responsive styling, and device light/dark mode.
- `script.js` handles the mobile menu, application form steps, and email preparation.
- `script.ts` is the TypeScript version of the website interactions. A browser needs it compiled to JavaScript before using it.
- `images/` contains the photos used on the site.

The beginner documentation explains HTML, CSS, Tailwind CSS, JavaScript, and TypeScript. This website uses regular CSS and JavaScript; Tailwind is discussed as a concept.

## Common questions

**Where is the website HTML?** In `index.html`.

**Where are the styles?** In `styles.css`.

**Where is JavaScript?** In `script.js`. That is the file loaded by the HTML page.

**Where is TypeScript?** In `script.ts`. It shows the same interactions with types and must be compiled before the browser can run it.

**Does the website have a portal or login?** No. It is now a public college website.

**Does it use a backend or database?** No.

**Are application documents uploaded?** No. The form only selects files locally and asks the user to attach them to the prepared email.

## Short presentation script

> “This is the Sam Ale College of Advanced Studies public website. It introduces the college, programmes, and admissions process. Visitors can complete a sample application enquiry and contact the college. The project uses HTML for page structure, CSS for its navy-and-gold design, and JavaScript for interactive forms. It is a front-end website only, with no student portal or backend.”
