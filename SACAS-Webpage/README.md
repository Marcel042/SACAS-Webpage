# SACAS College Website

This is a front-end-only public website for Sam Ale College of Advanced Studies. It contains college information, programmes, admissions application forms, and contact details. There is no student or college portal, no sign-in, no backend, and no database.

## Open the website

Double-click `index.html`. Keep the `images/` folder beside it so the photos appear. No server or extra software is needed to view the website.

## Main files

- `index.html` — the website content and application forms.
- `styles.css` — the SACAS design, responsive layout, and light/dark appearance.
- `script.js` — the navigation menu, application form steps, and email preparation.
- `script.ts` — a typed source version of the website interactions for learning. The page uses `script.js` directly in the browser.
- `images/` — the college crest and photographs used on the website.

The project also includes beginner explanations of HTML, CSS, Tailwind CSS, JavaScript, and TypeScript in [FRONTEND_DOCUMENTATION.md](./FRONTEND_DOCUMENTATION.md).

## Form limits

The website prepares an email for the visitor to review and send. It does not submit application data to the college or upload selected files. The phone and email links let a visitor contact admissions directly.
